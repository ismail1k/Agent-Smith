## Project Organization
Everything inside `src/`

### src/console
The **entry point** to the project, contain application command interfaces. <br>
Make a file inside and do a function/class, it will be discovered automatically.

### src/resources
All assets will be here.

#### src/resources/pydantics
Contain pyfantic models from subject

#### src/resources/templates
Contain prompt template that will be sent to the AI model
It can has dynamic variables
